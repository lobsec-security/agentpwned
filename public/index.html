API Reference

GET
/api/check/:agent_name
Check if an agent has been compromised. Returns all known incidents for the agent.
GET
/api/search?q=query
Search agents by partial name match. Returns matching agents with report counts.
GET
/api/feed?page=1&limit=20
Get the latest compromise reports with pagination. Default 20 per page.
GET
/api/stats
Aggregate statistics: totals, breakdowns by attack type, platform, severity.
POST
/api/report
Submit a new compromise report. Requires: agent_name, platform, attack_type, description.
GET
/api/types
List all valid attack types and severity levels accepted by the API.
